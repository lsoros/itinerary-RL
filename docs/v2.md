# Itinerary environment — v2 notes

Planned extensions after v1. The locked v1 contract remains [spec.md](spec.md). Nothing here changes that contract until it is promoted.

## Configurable illegal-request flag

v1 keeps the illegal flag out of the observation. The verifier is the only place an illegal request is penalized.

v2 should make that flag an environment config, default off, for training schemes that need bootstrapping. When on, the observation reports whether the last request was rejected. The single invalid bucket and the verifier penalty stay as they are.

## Eval entrypoint and graded score

v1 can score a finished trajectory and can search for ground truth. Those are separate calls.

v2 should add one eval path that takes an agent trajectory, the problem, the verifier list, and the dataset index, then reports how that trajectory compares with ground truth.

Intended grading shape:

- **1** — a perfect solution that matches the ground-truth path under the verifier weights
- **partial credit** — a viable reaching path that is feasible but subpar; weights decide how much
- **0** — invalid or infeasible

The raw weighted sum from v1 remains available underneath. The graded score is a reporting layer on top of it, not a second search.

## Same-city transfers

v1 keeps `same_airport_only: true` and does not implement `false`.

v2 should implement `same_airport_only: false` so a connection may change airports in the same city when the problem or environment config allows it. City fields stay attributes, not task endpoints. Success is still landing at the destination airport.

## Index cache

v1 rebuilds the generic-week index from the extract on every CLI or server start. That is enough for the January extract.

v2 should support an on-disk cache keyed by extract identity (path and content fingerprint, or an explicit dataset version). Load the cache when it matches; rebuild and write it when it does not. The public repo still does not store the extract.

## Explicitly still out of scope unless promoted later

These remain non-goals unless a later note says otherwise:

- A delay-rate term
- A live airline API
- A natural-language problem parser
- Round trips
- Shipping the multi-year extract in git
- Implementing the greedy policy inside this package (v1 leaves that to the user)
